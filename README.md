## 🚀 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/palleprashanthp4-dev/flipkart-clone-frontend.git
```

2. Open the project folder:

```text
Flipkart-Clone-Project-main
```

3. Open `index.html` in your browser.

For the best development experience, use **VS Code + Live Server**.

## ☁️ Vercel Deployment

The website's `index.html` is inside the `Flipkart-Clone-Project-main` directory.

When deploying to Vercel, set:

```text
Root Directory: Flipkart-Clone-Project-main
Framework Preset: Other
Build Command: Leave empty
Output Directory: .
```

Then deploy the project.
